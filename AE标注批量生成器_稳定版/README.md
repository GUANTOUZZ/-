# AE 标注批量生成器

稳定发布版，基于已确认可用的 v8.2.3 最终校准逻辑。

## 功能

用于 After Effects 中批量生成同一套标题/标注样式，并自动完成：

1. 修改文本 + 统一扩展画布
2. 批量 Auto Crop
3. 批量位置对齐
4. 批量导出渲染

## 默认参数

- Auto Crop 取样时间：3 秒
- 最终导出时长：10 秒
- 临时画布默认：3000 × 300
- 支持输出：
  - ProRes 4444 XQ + Alpha
  - ProRes 422 HQ

## 使用前准备

- After Effects
- 已安装可用的 Auto Crop 插件
- AE 菜单中可以直接执行：图层 → Auto Crop
- 工程中的标题模板文字层名称为：`标注`
- 需要提前在 AE 中保存好对应输出模块模板：
  - `ProRes4444XQ_Alpha`
  - `ProRes422HQ`

## 基础使用

1. 选择“导出合成”
2. 选择“标题模板”
3. 每行输入一条文字
4. 点击“一键执行四步流程”

如果需要逐步检查，可以切换到高级设置，依次执行四个步骤。

## 说明

- 原始标题模板不会被永久修改。
- 脚本会生成 `_REFERENCE` 和 `_EXPORT_XX` 合成用于处理。
- Auto Crop 后，各标题保留自己的实际尺寸。
- 所有修改后的标题会统一对齐到原版标题模板的位置。
- 导出采用单大合成逐层开关并立即渲染的方式，避免不同任务读取到错误图层状态。

# 本地高清视频下载 Skill：安装与操作

版本：1.1.0。推荐环境：Windows 10/11 64 位。它可以独立运行，也可以交给支持 SKILL.md 的智能体使用。不需要飞书、不需要 OpenAI API Key。

## 1. 解压到固定位置

右键 ZIP，选择“全部提取”。打开后应看到一个 `video-download` 文件夹，里面有 `SKILL.md`、`scripts`、`references`、`agents` 和本说明。不要只取其中一个 Python 文件，也不要直接在压缩包里运行。

可将文件夹放在“下载”目录，或任意有写入权限的位置。后面示例假设它在用户下载目录；如果不是，请修改第一条命令中的路径。

打开 PowerShell，输入：

```powershell
Set-Location "$HOME\Downloads\video-download"
Get-ChildItem
```

能看到 `SKILL.md` 和 `scripts` 即表示目录正确。路径有空格、中文时保留双引号。

## 2. 安装 Python

先检查：

```powershell
python --version
```

要求 Python 3.11 或更高。如果显示找不到命令或弹出商店，去 https://www.python.org/downloads/windows/ 安装 Python 3 的 64 位版本，勾选“Add python.exe to PATH”，安装后重新打开 PowerShell并再次进入 Skill 目录。

如果电脑只有 `py` 命令可用，可用 `py -3 --version` 检查，并将下一节创建虚拟环境的 `python` 换为 `py -3`。后续都用虚拟环境里的明确路径，不需要修改系统 Python。

## 3. 安装下载依赖

在 `video-download` 目录内逐行执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r .\scripts\requirements.txt
```

最后出现安装成功提示即可。这里使用独立虚拟环境，不要求执行 Activate.ps1，因此无需修改 PowerShell 执行策略。

若 pip 连接超时，确认本机网络或使用自己可用的代理，例如：

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\scripts\requirements.txt --proxy http://127.0.0.1:7890
```

7890 只是示例。没有运行对应代理软件时不要加这个参数。

## 4. 安装 FFmpeg

先检查下面两个命令：

```powershell
ffmpeg -version
ffprobe -version
curl.exe --version
```

如果 FFmpeg 或 ffprobe 不存在，在支持 winget 的 Windows 上执行：

```powershell
winget install --id Gyan.FFmpeg --exact
```

按安装程序提示完成，然后关闭并重新打开 PowerShell。也可以从 https://ffmpeg.org/download.html 选择 Windows 构建，解压后把包含 `ffmpeg.exe` 和 `ffprobe.exe` 的 `bin` 目录加入用户 PATH。

仅当前 PowerShell 临时添加路径的例子（改为真实路径）：

```powershell
$env:Path = "D:\Tools\ffmpeg\bin;" + $env:Path
```

## 5. 安装央视专用组件

普通网站使用 yt-dlp；央视高清还需要专用组件。执行：

```powershell
.\.venv\Scripts\python.exe .\scripts\install_cctv.py
```

安装器会下载固定版本、检查 SHA256，然后放进 Skill 的 `tools` 目录。成功时打印 `cctv-dl.exe` 的路径。不需要手动移动 DLL，也不要只保留 EXE。

GitHub 连接失败时可显式指定自己可用的代理：

```powershell
.\.venv\Scripts\python.exe .\scripts\install_cctv.py --proxy http://127.0.0.1:7890
```

安装器不自动运行发行包中的其他安装程序。若提示缺少运行库，先确认没有丢失同目录 DLL；确需运行库时从微软官方安装 Visual C++ 运行库。

## 6. 首次下载

先用以下示例下载一条央视视频：

```powershell
.\.venv\Scripts\python.exe .\scripts\download.py "https://tv.cctv.com/2017/03/17/VIDE1rV2if1tZy9Wug7FDTln170317.shtml" --output "$HOME\Downloads\Videos"
```

其他网站直接替换 URL；支持单条视频，不批量下载整个账号。下载、合并和全片校验期间可能暂时没有终端输出。最后 `ok: true` 表示完成，`path` 是视频路径，`quality_report` 是分辨率等信息报告。

默认输出目录为运行命令时所在目录下的 `downloads`。每次任务有独立子目录，防止上次残片被误当作新结果。

不要根据文件名猜画质。打开旁边的 `.quality.json` 查看 `streams` 中的 `width`、`height`；`format.duration` 单位是秒，`format.size` 单位是字节。全片解码会占用 CPU，长视频需要等待。

## 7. 最高画质、登录和代理

程序自动选择当前可访问的最高分辨率，再比较码率和帧率。网站写着“1080P”不代表匿名接口一定开放 1080P；没有权限的会员档不会被强行解锁。

只查看网站返回的格式，不下载视频：

```powershell
.\.venv\Scripts\python.exe .\scripts\download.py "视频链接" --list-formats
```

已登录浏览器且愿意将登录态用于本次下载时：

```powershell
.\.venv\Scripts\python.exe .\scripts\download.py "视频链接" --cookies-from-browser chrome --output "$HOME\Downloads\Videos"
```

也支持 `edge`、`firefox`，取决于 yt-dlp 支持情况。Chrome 数据库占用或解密失败时，工具不能保证读取成功。不要把 Cookie 文件发给别人；使用自己的 Netscape 格式 Cookie 文件时：

```powershell
.\.venv\Scripts\python.exe .\scripts\download.py "视频链接" --cookies "$HOME\Downloads\cookies.txt"
```

网络需要代理时：

```powershell
.\.venv\Scripts\python.exe .\scripts\download.py "视频链接" --proxy http://127.0.0.1:7890
```

代理对 yt-dlp、Python 请求及央视缺片恢复生效；央视原生组件是否使用环境代理取决于 Qt/系统网络配置，不能只凭传参断言所有请求都经过代理。

## 8. 央视超时与恢复

1.1.0 不再把某个卡住的原生下载进程一直等到结束：单次最多等待 90 秒，停止后读取分片状态，用 curl 补下缺失分片，再以 2 线程恢复原生处理。最多三轮，恢复过程共享 `--timeout` 时间预算；不会改变画质档。

默认预算 900 秒。慢网络或长视频可以增加：

```powershell
.\.venv\Scripts\python.exe .\scripts\download.py "央视链接" --timeout 1800 --output "$HOME\Downloads\Videos"
```

只有成功下载且 TS 结构检查通过的分片才标记完成；最终 MP4 还要通过分辨率和完整解码检查。恢复日志在任务目录的 `cctv_native/recovery.json`。跨命令重新运行会创建新任务目录，目前不是跨任务自动续传。

## 9. 接入 Codex 或其他智能体

独立命令行确认可用后，把整个 `video-download` 文件夹复制到：

```text
Windows: %USERPROFILE%\.codex\skills\video-download
macOS/Linux: ~/.codex/skills/video-download
```

如果配置了 CODEX_HOME，使用该目录下的 `skills`。在最终安装位置重新创建 `.venv` 并安装依赖；Python 虚拟环境不适合直接搬家。央视 tools 目录可以一起复制。

重新打开会话，输入：“使用 $video-download，把这个链接的视频以最高可访问画质下载到本地。”提醒智能体使用此文件夹 `.venv` 中的 Python。其他宿主按其导入 SKILL.md 的方式安装，不保证所有宿主支持同样的导入方式。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| No module named yt_dlp | 使用 `.venv\Scripts\python.exe`，并用同一解释器安装 requirements |
| 找不到 ffmpeg/ffprobe | 添加 PATH 后重新打开终端，分别运行版本命令确认 |
| 403、验证码、登录失败 | 确认浏览器可播放；在授权范围内使用自己的 Cookie，不无限重试 |
| 央视缺少专用工具 | 运行第 5 节安装器；保留 tools 下整个目录 |
| 下载后没有可交付 MP4 | 查看终端错误和任务目录日志，不使用 `.part` 残片 |
| 实际分辨率低于网页选项 | 检查登录态和接口提供的格式，不通过放大画面伪造高清 |
| 优酷偶尔超时 | 确认站点连接，必要时显式代理；网络失败不等于格式不支持 |
| 快手链接失败 | 尚无确认可用的专用链路，不承诺支持 |

## 11. 分享与更新

分享原始 ZIP 即可。不要把自己安装后的 `.venv`、tools、下载视频、Cookie、`.quality.json` 或日志重新压缩分享。原始 ZIP 不含任何账号登录态；接收者在自己的电脑上安装依赖。

站点改版时可在虚拟环境更新 yt-dlp，但更新后原验证记录不代表新版本：

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade "yt-dlp[default]"
```

完整支持范围和测试结果见 `references/sites.md`、`references/validation.md`。纯下载无 GPT API 消耗，但调用本 Skill 的智能体宿主可能仍收取模型使用费用。

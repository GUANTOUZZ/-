# 基地视频框替换：完整使用说明

## 1. 脚本用途

“视频框替换”用于已经适配好的 AE 模板。你只需要选择一个占位位置、加入一组视频，脚本就会为每条视频生成一份独立的导出合成并加入渲染队列。

它主要解决以下问题：

- 多条视频需要反复套入同一个 AE 模板。
- 替换后必须保留原图层的层级位置，不能跑到最顶层。
- 新视频比原模板长时，最终合成、嵌套合成和装饰图层需要一起延长。
- 每条视频要生成独立合成，避免上一条的时长或素材污染下一条。
- 替换完成后要先检查合成，再单独触发渲染。
- 渲染时只处理刚刚生成的批次，避免误渲染旧队列。

推荐工作流是：新模板只适配一次，适配完成后长期使用这份稳定脚本批量生产。

## 2. 运行环境

### 2.1 已验证环境

- Windows 10/11
- Adobe After Effects 25.0、26.0
- Adobe Media Encoder 与 AE 版本相匹配
- 脚本类型：ExtendScript / ScriptUI Panel（`.jsx`）

轨道遮罩的自动保留使用 `setTrackMatte`，因此带轨道遮罩的文字层或形状层建议使用 AE 23.0 或更新版本。

### 2.2 AE 首选项

打开：

```text
编辑 → 首选项 → 脚本与表达式
```

勾选：

```text
允许脚本写入文件和访问网络
```

该权限用于文件选择、输出位置、诊断日志和渲染路径设置。

### 2.3 Media Encoder

面板的“渲染”按钮采用安全方式把队列发送到 Adobe Media Encoder，避免 AE 在直接阻塞渲染时界面卡死或闪退。

第一次使用前应：

1. 安装与 AE 兼容的 Adobe Media Encoder。
2. 手动启动 AME 一次，等待它完成初始化。
3. 关闭 AME 或保持打开均可。

## 3. 安装教程

### 3.1 推荐安装位置：当前 Windows 用户

完全退出 AE，把 `视频框替换.jsx` 复制到：

```text
%APPDATA%\Adobe\After Effects\<版本号>\Scripts\ScriptUI Panels\
```

常见示例：

```text
C:\Users\你的用户名\AppData\Roaming\Adobe\After Effects\25.0\Scripts\ScriptUI Panels\视频框替换.jsx
C:\Users\你的用户名\AppData\Roaming\Adobe\After Effects\26.0\Scripts\ScriptUI Panels\视频框替换.jsx
```

如果 `Scripts\ScriptUI Panels` 不存在，可手动创建。

### 3.2 备用安装位置：AE 程序目录

也可安装到 AE 程序目录下的：

```text
Support Files\Scripts\ScriptUI Panels\
```

该位置通常需要管理员权限。多人分发时更推荐使用当前用户目录，升级和替换都更方便。

### 3.3 打开并固定面板

1. 重新启动 AE。
2. 打开“窗口 → 视频框替换”。
3. 拖动面板标题，把面板停靠到 AE 工作区。
4. 调整到能完整看到底部按钮的高度。
5. 保存当前工作区。

下一次启动 AE 时，面板通常会随工作区一起恢复。

### 3.4 更新脚本

1. 完全退出 AE。
2. 用新文件覆盖旧的 `视频框替换.jsx`。
3. 重新启动 AE。

不要同时保留多个不同名称的旧版 `.jsx`，否则“窗口”菜单会出现多个相似面板，容易打开错版本。

## 4. 模板准备

### 4.1 来源合成

来源合成是实际包含“被替换图层”的合成。被替换图层可以是：

1. 视频或纯色等素材图层，且其 `source` 属于 FootageItem。
2. 二维形状图层。
3. 二维文字图层。

图层名称没有强制要求。建议使用容易识别的名称，例如：

```text
[视频素材占位] 替换此层
```

### 4.2 最终合成

最终合成是希望加入渲染队列的最外层合成。

推荐将默认最终合成命名为：

```text
视频框-最终
```

面板会优先选中这个名称。没有这个名称时，需要手动选择正确的最终合成。

### 4.3 嵌套关系

最稳定的结构是：

```text
最终合成
└─ 中间合成（可有多层）
   └─ 来源合成
      └─ 替换图层
```

脚本会查找从最终合成到来源合成的嵌套路径，并为每条视频复制整棵导出依赖树。

如果最终合成没有引用来源合成，脚本会询问是否把替换后的来源合成新增到最终合成副本。选择“是”后，新层会：

- 放在最终合成当前工作区起点。
- 居中。
- 使用 100% 缩放。
- 保留最终合成原有图层之间的顺序。

这种模式适合独立模板拼接，但需要人工检查新增层的位置与大小。

### 4.4 主路径限制

从来源合成到最终合成的主嵌套路径应满足：

- 不启用时间重映射。
- 不使用倒放。
- 时间伸缩必须大于 0。
- 来源合成不能形成循环引用。

其他装饰分支中的时间重映射会尽量保留，脚本通过采样和关键帧读取计算所需源时长，但仍建议对复杂时间动画进行人工检查。

## 5. 面板字段与配置明细

| 字段 | 作用 | 推荐设置 | 注意事项 |
|---|---|---|---|
| 来源合成 | 选择真正包含占位层的合成 | 先在时间轴打开来源合成，再打开或刷新面板 | 默认优先当前活动合成 |
| 替换图层 | 选择要替换的素材、形状或文字层 | 使用清楚的占位命名 | 下拉框会显示层序号、层名和类型 |
| 最终合成 | 选择最终导出的最外层合成 | 命名为“视频框-最终” | 选错会生成错误的导出链路 |
| 刷新列表 | 重新读取工程中的合成和可替换层 | 新增、重命名合成后点击 | 刷新后再次核对三个选择项 |
| 新视频顺序 | 决定批次顺序 | 按最终所需顺序添加 | 每个视频生成一份独立合成 |
| 添加视频 | 选择一个或多个视频 | 可一次多选 | 支持列表过滤：mp4、mov、m4v、avi、mxf、webm；实际解码取决于 AE |
| 移除 | 删除当前选中的列表项 | 加错时使用 | 不会删除磁盘文件 |
| 命名 | 生成合成的名称前缀 | 默认“视频框” | Windows 非法字符会替换为下划线，空名称会报错 |
| 版本 | 生成合成的版本号 | V1–V20 | 输出为小写 `_v1` 至 `_v20` |
| 输出位置 | 渲染文件保存目录 | 每次渲染前重新确认 | 关闭或重开面板后需要重新选择 |
| 替换并加入队列 | 执行复制、替换、时长同步和入队 | 先执行此按钮 | 不会立即渲染 |
| 渲染 | 发送刚加入的批次到 AME | 检查合成后再点击 | 不会重新替换，也不会处理未被本批次记录的旧队列 |

## 6. 完整使用教程

### 第一步：打开正确的工程和合成

1. 打开已经适配好的 `.aep` 工程。
2. 在时间轴中打开真正包含占位层的来源合成。
3. 如果可以，先选中要替换的图层。
4. 从“窗口 → 视频框替换”打开面板。

打开面板时，如果来源合成中只有一个图层被选中，面板会优先选中对应的兼容图层。

### 第二步：选择来源、替换层和最终合成

1. “来源合成”选择包含占位层的合成。
2. “替换图层”选择正确层。下拉框类型可能显示：

   ```text
   [文字图层]
   [形状图层]
   [素材文件名]
   ```

3. “最终合成”选择最终输出的最外层合成。

如果刚刚添加或重命名了合成，点击“刷新列表”。

### 第三步：添加视频

1. 点击“添加视频”。
2. 可以一次选择多个文件。
3. 文件会按照列表顺序处理。
4. 加错文件时，选中该行并点击“移除”。

脚本只接受有画面、具有有效时长的视频文件。静态图片和纯音频会被拒绝。

### 第四步：设置命名和版本

默认：

```text
命名：视频框
版本：V1
```

当列表中有三条视频时，将生成：

```text
视频框1_v1
视频框2_v1
视频框3_v1
```

改为 `V2` 后将生成：

```text
视频框1_v2
视频框2_v2
视频框3_v2
```

如果工程中已经存在同名合成，脚本会继续添加 `_2`、`_3` 等后缀，避免覆盖。

### 第五步：选择输出位置

点击“选择…”并指定本批次的输出文件夹。

输出文件名使用原始输入视频的文件名，不使用合成名称。例如：

```text
输入：2013.mp4
输出：2013.mp4（或由当前输出模块决定的扩展名）
```

如果同名文件已经存在，脚本会自动生成：

```text
2013_2.mp4
2013_3.mp4
```

脚本只设置输出目录和文件名。编码器、封装格式、码率、音频和质量由 AE/AME 当前渲染预设决定。

### 第六步：替换并加入队列

点击“替换并加入队列”。脚本会依次：

1. 导入每条新视频。
2. 为当前视频复制来源合成、最终合成和相关嵌套合成。
3. 在副本中替换指定图层。
4. 保持替换层的视觉层级位置。
5. 将视频出点设置为“占位层入点 + 新视频时长”。
6. 按嵌套关系换算视频在最终合成中的实际导出起止时间。
7. 递归延长导出树中所有可见图层与嵌套合成。
8. 把最终副本加入 AE 渲染队列。
9. 打开生成的最终合成，方便检查。

成功后会弹出每条视频的素材时长、合成名、导出入点和队列时长。

### 第七步：逐条检查

进入生成的合成，至少检查：

- 替换视频是否处于正确层级。
- 位置、缩放、旋转是否正确。
- 视频是否正确填满画框。
- 遮罩和轨道遮罩是否正确。
- 文字、边框、装饰线和背景是否仍然可见。
- 最终合成时长是否到达视频结尾。
- 嵌套合成内的可见图层是否延长到合成结尾。
- 最后几帧是否黑屏、丢装饰或出现透明区域。
- 音频是否需要保留、静音或另行处理。

如果结果不正确，可立即执行一次 `Ctrl+Z` 撤销本次批处理，然后先修正模板。

### 第八步：渲染

确认无误后回到面板，点击“渲染”。

脚本会：

1. 再次检查刚加入队列的时间范围是否合法。
2. 设置每个队列项的输出路径。
3. 暂时只勾选本批次队列项。
4. 将本批次发送到 Adobe Media Encoder。
5. 恢复其他旧队列项原来的启用状态。

它不会重新替换视频，也不会调用会阻塞 AE 界面的直接渲染。

发送到 AME 后，应在 AME 中再次确认输出格式、预设和保存位置，然后观察渲染状态。

## 7. 三类替换层的具体行为

### 7.1 视频或素材占位层

- 直接在原图层上替换 Source。
- 原图层索引和层级位置不变。
- 保留图层名称。
- 保留位置、缩放、旋转、关键帧、蒙版、效果、混合模式和轨道遮罩等原图层属性。
- 保留原入点。
- 出点改为“入点 + 新视频完整时长”。

这是最稳定、最推荐的占位方式。

### 7.2 形状层占位

- 根据形状层实际可见范围计算视频画框。
- 用 Cover 方式等比放大视频，保证画框被填满；多出的部分会被裁出画框。
- 新视频放到原形状层所在的视觉堆叠位置，而不是移动到最顶层。
- 复制可转移的图层标记、透明度动画、效果和轨道遮罩。
- 原形状层如果仍被其他层用作轨道遮罩，会被保留并关闭可见性；否则会删除。

复杂的形状动画、形状内容属性和直接绘制在形状层上的特殊结构不会完整转换成视频属性。正式模板优先使用素材占位层或独立轨道遮罩。

### 7.3 文字层占位

- 根据文字层或其轨道遮罩的可见范围计算视频画框。
- 有轨道遮罩时，以 Cover 方式填满遮罩范围。
- 无轨道遮罩时，保留可转移的缩放、旋转和透明度动画，并把视频中心放到文字可见范围中心。
- 新视频插入到文字层原有视觉位置附近，原文字层被关闭。
- 二维文字和二维父级可用；三维文字层或三维父级会被拒绝。

文字逐字动画、文本动画器、复杂表达式只用于计算可见范围，不会变成视频图层动画。正式生产建议先进行一次试替换。

## 8. 时长同步规则

脚本的目标是：在最终导出合成中，所有能够显示的图层和嵌套合成至少延长到新视频结尾。

具体规则：

1. 新视频保留占位层入点。
2. 新视频出点为“入点 + 视频时长”。
3. 合成时长向上对齐到完整帧。
4. 从来源合成向最终合成逐级换算时间伸缩和起始时间。
5. 每个批次使用独立的合成副本；不同视频时长互不影响。
6. 递归遍历最终副本中的嵌套合成。
7. 眼睛开关开启、且入点位于合成有效范围内的图层会延长到合成结尾。
8. 眼睛关闭的图层及其私有嵌套分支不会被强制延长。
9. 只延长合成时长和图层出点，不会自动拉伸已有关键帧节奏。最后一个关键帧之后通常保持最后状态。
10. 渲染范围按帧对齐，并写入合成工作区和队列项。

如果模板中有“本来就应该提前消失”的可见图层，本脚本也可能把它延长到结尾。这是当前需求定义的一部分。需要提前消失的动画应通过透明度关键帧、效果或预合成内部动画控制，而不要只依赖图层出点。

## 9. 原工程保护与撤销

- 脚本不直接改写原始模板合成，而是复制完整导出树后修改副本。
- 每条视频有独立副本，共享预合成只在该条输出内部共享。
- 成功执行后，工程中会新增导入素材、批次合成和渲染队列项。
- 一次批处理位于同一个 AE 撤销组中，需要取消时可执行一次 `Ctrl+Z`。
- 建议批处理前保存工程，检查无误后再另存生产版本。

## 10. 推荐生产流程

### 新模板第一次使用

1. 用 AI 或人工分析模板结构。
2. 明确来源合成、替换层和最终合成。
3. 把替换位置改成稳定的二维素材占位层或轨道遮罩结构。
4. 用横版、竖版、短视频和长视频各试一条。
5. 检查缩放、位置、遮罩、动画和递归时长。
6. 保存为“已适配模板”。

### 日常批量

1. 打开已适配模板。
2. 打开固定面板。
3. 选择视频列表、命名、版本和输出位置。
4. 替换并加入队列。
5. 抽查生成合成。
6. 渲染。

日常批量不需要重新让 AI 操作每一条视频，能明显减少耗时和模型额度。

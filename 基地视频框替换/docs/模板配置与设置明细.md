# 模板配置与设置明细

## 一、推荐模板结构

```text
视频框-最终                     ← 面板“最终合成”
├─ 背景与装饰预合成
├─ 视频框包装预合成
│  └─ 视频框                   ← 面板“来源合成”
│     ├─ 前景边框
│     ├─ [视频素材占位]替换此层 ← 面板“替换图层”
│     └─ 背景
└─ 其他可见装饰
```

模板可以有多层嵌套。只要最终合成能够沿预合成层找到来源合成，脚本就会复制这条路径及其完整导出依赖。

## 二、合成设置

### 来源合成

- 分辨率：按模板设计设置。
- 帧率：建议与最终合成一致。
- 像素长宽比：建议与最终合成一致。
- 时长：可以是模板默认时长，脚本会按新视频需要延长副本。
- 工作区：不作为视频长度的唯一依据；脚本会重新设置批次副本工作区。

### 最终合成

- 推荐名称：`视频框-最终`。
- 分辨率和帧率：应为最终交付规格。
- 应包含来源合成或通过中间预合成间接包含来源合成。
- 最终合成当前工作区起点仅在“最终合成未引用来源合成”的独立插入模式中作为新增层入点。

### 中间预合成

- 正向时间伸缩可以使用，脚本会换算时长。
- 来源到最终的主路径不要使用时间重映射。
- 主路径不要倒放或把 Stretch 设为 0/负数。
- 避免循环引用。

## 三、替换层设置

### 推荐方案 A：普通素材占位层

这是最可靠的方案。

建议设置：

- 使用纯色、测试视频或占位图片作为 Source，但该图层必须被 AE 识别为 FootageItem。
- 在该层上完成位置、缩放、旋转、蒙版、效果、混合模式、父子关系和关键帧。
- 名称建议：`[视频素材占位]替换此层`。
- 把图层放在最终需要的堆叠位置。

替换时会在原图层上调用 Source 替换，所以层级和大多数属性天然保留。

### 方案 B：形状层占位

适合简单矩形、圆角矩形或其他二维图形作为画框参考。

要求：

- 图层及其父级必须是二维。
- 可见范围不能为零。
- 画框应在图层有效时间内可见。
- 复杂遮罩优先使用独立轨道遮罩层。

适配方式为 Cover：

```text
缩放比例 = max(画框宽 / 视频宽, 画框高 / 视频高)
```

因此视频一定填满画框，但宽高比不一致时会裁掉两侧或上下区域。

### 方案 C：文字层占位

适合把一块文字可见范围临时当作视频区域。

要求：

- 文字层及其父级必须是二维。
- 文字在合成有效时间内至少有一个可见尺寸。
- 带轨道遮罩时使用 AE 23.0 或更高版本。

脚本会在当前时间及图层有效区间内采样可见范围。对于逐字动画、路径文字或复杂文本动画器，必须先试替换确认。

## 四、遮罩设置

按稳定性排序：

1. 普通素材占位层上的蒙版。
2. 独立的轨道遮罩层。
3. 预合成内部完成裁切。
4. 直接依赖复杂形状或文字动画计算范围。

素材占位层直接替换 Source，因此原层蒙版可以完整保留。形状层和文字层会创建新视频层，复杂的原层内部属性不会全部转换；这两种情况推荐使用独立轨道遮罩。

## 五、层级与叠放顺序

- 素材占位层：原位替换，层索引不变。
- 形状层：新视频插入到原形状层前方；原层删除或作为遮罩保留并关闭。
- 文字层：新视频插入到原文字层前方，原文字层关闭。
- 新视频不会直接移动到合成最顶层。

使用形状或文字占位时，原层附近如果有依赖相邻层顺序的旧式轨道遮罩，建议在 AE 23+ 中改成可明确指定遮罩层的新轨道遮罩结构。

## 六、时长和动画设置

### 会自动同步的内容

- 新视频图层出点。
- 来源合成副本时长。
- 最终合成副本时长。
- 中间预合成副本时长。
- 导出树中可见图层的出点。
- 需要继续显示的嵌套装饰合成。
- 合成工作区和渲染队列时间范围。

### 不会自动重定时的内容

- 关键帧之间的动画节奏。
- 表达式内部写死的秒数或帧数。
- 粒子、模拟、缓存类效果的内部寿命。
- 第三方插件自身的时长参数。
- 音频淡入淡出关键帧。
- 被关闭图层的时长。

如果装饰需要一直显示到结尾，可让最后关键帧自然保持。如果装饰需要在结尾重新执行一段出场动画，需要在模板适配阶段用表达式或专门控制层完成。

## 七、命名配置

面板按以下规则生成合成名：

```text
命名字段 + 批次序号 + "_v" + 版本数字
```

示例：

| 命名 | 版本 | 第 1 条 | 第 2 条 | 第 3 条 |
|---|---|---|---|---|
| 视频框 | V1 | 视频框1_v1 | 视频框2_v1 | 视频框3_v1 |
| 视频框 | V2 | 视频框1_v2 | 视频框2_v2 | 视频框3_v2 |
| 基地视频框 | V10 | 基地视频框1_v10 | 基地视频框2_v10 | 基地视频框3_v10 |

规则：

- 版本仅允许 V1–V20。
- Windows 文件名非法字符会变成 `_`。
- 名称过长会自动截断。
- 工程内重名时自动添加 `_2`、`_3`。

## 八、输出和编码配置

脚本不修改渲染模板或编码参数，以下项目由 AE/AME 当前设置决定：

- 视频编码器，例如 H.264、ProRes。
- 封装格式，例如 MP4、MOV。
- 分辨率缩放。
- 帧率转换。
- 码率和质量。
- 是否包含音频。
- 色彩管理和 Alpha 通道。

推荐做法：

1. 在正式批量前用一条视频测试。
2. 发送到 AME 后选择团队统一预设。
3. 确认扩展名与编码匹配。
4. 确认输出目录空间充足。
5. 再开始整个批次。

输出文件基础名取自输入视频名；同名冲突自动加数字后缀。

## 九、模板验收用测试素材

新模板至少测试四种素材：

1. 与画框同宽高比的短视频。
2. 与画框同宽高比的长视频。
3. 比画框更宽的视频。
4. 比画框更高的视频。

验收重点：

- 层级是否正确。
- Cover 裁切方向是否能接受。
- 蒙版是否完整。
- 父级动画是否保持。
- 长视频结尾的所有装饰是否仍可见。
- 短视频导出是否准确停止。
- 最后一帧是否完整。

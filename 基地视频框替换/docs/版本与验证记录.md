## 本版主要能力

- 可停靠 ScriptUI 面板。
- 支持视频素材层、二维形状层和二维文字层。
- 替换层保持原视觉堆叠位置。
- 每条视频生成独立最终合成。
- 命名支持 V1–V20，例如 `视频框1_v1`。
- 复制完整导出树，不直接改写原模板合成。
- 递归延长嵌套合成与可见图层。
- 队列时间范围按帧对齐并做越界校验。
- “渲染”只处理刚加入的批次，不重新替换。
- 使用 Adobe Media Encoder 安全渲染，避免 AE 阻塞渲染造成的闪退风险。
- 面板重开后可从带标记的待处理队列项恢复批次记录。

## 自动回归验证

已通过 18 项模拟 AE API 回归检查：

1. 24 秒素材替换保持层级、名称、变换和锁定状态。
2. 不同批次时长互不污染模板和先前输出。
3. 短视频使用精确导出范围。
4. 起点偏移和正向时间伸缩正确换算。
5. 来源合成与最终合成为同一合成时可工作。
6. 被提前裁短的可见预合成会延长。
7. 关闭图层及其私有分支不会强制延长。
8. 非主路径时间重映射保留且不重写关键帧。
9. 共享分支按最长需求延长。
10. 形状层替换保持原堆叠位置。
11. 文字层替换保持原堆叠位置。
12. 独立最终合成插入模式会延长背景树。
13. 输出使用输入素材名、保留输出模块扩展名并避免重名。
14. 写入队列起点前先缩短时间范围，覆盖 5.6 秒合成边界案例。
15. 起点位于合成结尾时会在写队列前拒绝。
16. 正确的整段队列范围不会被重复改写。
17. 安全渲染只发送当前批次，并恢复旧队列启用状态。
18. V1–V20 顺序命名正确。

这些检查使用模拟 AE API，不替代真实模板的视觉检查。新模板仍应使用至少一条短视频和一条长视频进行实际试替换与渲染。

# 常见问题与排错

## 1. “窗口”菜单里没有“视频框替换”

检查：

1. 文件名是否为 `视频框替换.jsx`。
2. 是否放在当前 AE 版本的 `Scripts\ScriptUI Panels` 中。
3. 复制脚本时 AE 是否已经完全退出。
4. 是否重新启动了 AE。
5. 是否误装到了另一个 AE 大版本目录。

## 2. 面板每次打开都很小

把面板拖入 AE 工作区停靠，拉到能看见底部按钮的高度，然后保存工作区。独立浮动窗口和临时脚本窗口不会可靠保存布局。

## 3. 下拉列表中找不到合成或图层

- 点击“刷新列表”。
- 确认工程中的对象是 CompItem。
- 替换图层仅显示文字层、形状层和 Source 为 FootageItem 的 AV 图层。
- 摄像机、灯光、空对象和普通预合成层不会列为替换层。

## 4. 提示“请选择有时长的视频文件”

所选文件是静态图片、纯音频、损坏文件，或 AE 无法把它识别为有画面的视频。先在 AE 中手动导入验证解码是否正常。

## 5. 提示“文字替换暂不支持三维图层或三维父级”

文字或形状的可见边界需要在二维坐标中计算。把占位层及其父级改为二维，或改用普通素材占位层。

## 6. 提示“保留遮罩需要 AE 23.0 或更新版本”

当前占位层使用了轨道遮罩，而 AE 版本不支持脚本指定遮罩层。升级 AE，或把结构改成普通素材占位层/预合成裁切。

## 7. 提示“嵌套图层启用了时间重映射”

来源合成到最终合成的主路径中存在时间重映射。关闭该预合成层的时间重映射，再运行脚本。需要变速时，优先使用正数时间伸缩，并完成一次测试。

## 8. 提示“使用了倒放或无效时间伸缩”

主路径中的某个预合成层 Stretch 为 0 或负数。改为正数。倒放模板不能自动可靠换算新视频的最终范围，需要单独适配。

## 9. 最终合成未引用来源合成

说明当前选择的最终合成中找不到来源合成。

处理方法：

- 如果选错了最终合成，取消并重新选择。
- 如果本来就是独立合成，确认后允许脚本新增来源合成副本。新增层会居中、100% 缩放，并从最终合成工作区起点开始；之后必须检查位置和缩放。

## 10. 替换视频跑到顶层

当前版本不会把素材占位层移动到顶层：

- 素材占位直接原位换源。
- 形状/文字占位的新视频插到原占位层前方。

如果视觉顺序仍不正确，检查模板是否依赖旧式相邻轨道遮罩、调整图层或表达式。优先改用普通素材占位层。

## 11. 视频位置、缩放或蒙版错误

按以下顺序排查：

1. 确认选中的确是设计好的占位层。
2. 普通素材占位应在该层上预先设置蒙版、位置和缩放。
3. 形状/文字占位使用 Cover，会裁掉宽高比不匹配的区域。
4. 检查占位层和父级是否为二维。
5. 检查表达式是否引用了具体图层索引或旧 Source 尺寸。
6. 把复杂裁切改为独立轨道遮罩或预合成。
7. 用一条横版和一条竖版视频分别试替换。

## 12. 装饰合成没有延长

脚本只强制延长眼睛开关开启、且入点在有效范围内的图层。检查：

- 图层是否被关闭。
- 图层是否在新合成结尾之后才入场。
- 是否由表达式或效果自行关闭。
- 第三方效果是否有独立寿命。
- 是否查看了原模板，而不是生成的批次副本。

脚本延长图层出点，不会把动画关键帧整体移动到新结尾。

## 13. 出现 timeSpanStart 或渲染范围越界警告

当前版本会先把队列时长临时缩到一帧，再写入起点和最终时长，用来避免 AE 在写入中间状态时判定越界。

如果仍出现警告：

1. 不要继续渲染该项。
2. 在渲染队列中把“时间范围”设为“仅工作区”。
3. 确认工作区结尾不超过合成时长。
4. 删除异常队列项并重新执行“替换并加入队列”。
5. 确认使用的是最新版 `视频框替换.jsx`。

诊断日志位于：

```text
%TEMP%\ae-batch-render-range.log
```

日志记录合成时长、工作区、队列起点和队列时长，可用于定位问题。

## 14. 点击“渲染”后 AE 闪退

当前版本不再调用 AE 的阻塞式 `renderQueue.render()`，而是把本批次发送到 AME。

仍有问题时：

1. 确认 AME 已安装并成功单独启动。
2. 确认 AE 与 AME 大版本兼容。
3. 先在 AE 菜单中手动测试“在 Adobe Media Encoder 队列中添加”。
4. 临时关闭可能拦截 Dynamic Link 的安全软件。
5. 用单条视频、默认编码预设测试。
6. 检查第三方插件是否在打开合成时崩溃。

## 15. “渲染”按钮不可点

只有面板识别到待渲染的脚本批次时按钮才启用。

- 先点击“替换并加入队列”。
- 如果重开面板，工程必须仍保留脚本生成的队列项和合成注释标记。
- 已删除队列项后不能仅凭生成合成恢复渲染按钮。

## 16. 点击“渲染”提示没有选择输出位置

输出目录不会跨面板会话永久保存。每次重开面板后重新点击“选择…”。

## 17. 输出不是 MP4

脚本没有硬编码 H.264。输出扩展名和编码由 AE/AME 当前预设决定。进入 AME 后选择 H.264 预设，并确认输出扩展名为 `.mp4`。

## 18. 只想渲染刚才的队列

直接点击面板“渲染”。脚本会临时只启用当前记录的批次，发送到 AME 后恢复其他队列项状态。它不会再次执行替换。

## 19. 想取消刚才生成的整批内容

在没有继续做其他 AE 操作时执行一次 `Ctrl+Z`。建议批处理前先保存工程，以便在复杂情况下直接关闭且不保存。

## 20. 如何确认脚本版本正确

```text

```

Windows PowerShell 检查命令：

```powershell

```
